# oui — космическая аркада

Лети вперёд по маршруту около планеты, маневрируй и разбивай астероиды. За каждый из восьми этапов открывается корабль: от стартового «Пионера» до «Небулы», всего девять моделей с разными характеристиками.

Тестовый сайт: [открыть oui](https://alitojcubekov206-svg.github.io/oui/).

## Запуск на компьютере

Нужен Node.js 22 или новее. Из корня репозитория:

```powershell
cd github-deployment-and-commands
npm ci
npm run dev
```

Открой адрес, который напишет терминал. Остановка сервера — Ctrl+C.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD или стрелки | Манёвры вверх, вниз, влево, вправо |
| Пробел или J | Стрельба, можно удерживать |
| Shift | Форсаж |
| X | Торможение |
| C | Камера |
| Esc или P | Пауза |

На телефоне стрелки находятся слева, огонь и форсаж — справа. Можно нажимать несколькими пальцами одновременно. Камера переключается кнопкой рядом со счётом. Доступны вертикальный и горизонтальный экраны. В настройках есть автоматическая стрельба и режим производительности.

После восьми секунд без столкновений щит восстанавливается. При сворачивании полёт останавливается до нажатия «Продолжить». Победа открывает следующий этап и корабль; повторные победы не дублируют награду.

## Прогресс

Позывной, настройки, выбранный корабль, пройденные этапы и последние 100 вылетов сохраняются в этом браузере. Старые результаты первой версии переносятся. Выход из незавершённого полёта не записывает результат.

В настройках можно сбросить прогресс с подтверждением. Очистка данных сайта также удалит сохранения. Синхронизации между устройствами нет. Интернет нужен для открытия веб-версии; во время полёта внешние ресурсы не загружаются.

## Проверки и сборка

```powershell
npm run typecheck
npm run build -- --base=/oui/
npx playwright install chromium
npm test
```

Тесты сами запускают локальный сервер готовой сборки. На Windows можно использовать установленный Edge:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm test
```

Проверяются меню на экранах 320/390/720 px, управление несколькими пальцами, камера, форсаж, пауза, все восемь этапов, открытие кораблей и сохранения после перезагрузки. В тесте этапов используется фиксированное расположение астероидов и ускоренные временные метки кадров; это проверка игровой логики, а не измерение FPS телефона. Снимки экранов сохраняются в игнорируемой папке test-results.

Графика требует WebGL 2. Производительность и нагрев нужно проверить на настоящем телефоне. Android-приложение — следующий этап после проверки сайта.

## Публикация

Workflow Deploy oui to Pages в корневой папке .github/workflows запускается при push в main. Он устанавливает зависимости из package-lock.json, проверяет типы, собирает сайт и запускает браузерные тесты перед публикацией.

Статус публикации: [GitHub Actions](https://github.com/alitojcubekov206-svg/oui/actions/workflows/deploy.yml). В Settings → Pages используется источник GitHub Actions. Если браузер показывает старую версию, обнови страницу без кэша.
